# Tells

Load this file when a draft still sounds like a model. Each tell has a
replacement.

## Overused words

Prefer a plain verb. Typical tells: "delve", "tapestry", "landscape", "robust",
"leverage".

Before: We leverage the cache to unlock a more robust query experience.
After: We use the cache to make repeated queries faster.

## Empty emphasis

Drop words that add stress but no fact: "really", "real", "matters", "worth",
"carries weight", "boasts", "a testament to", "pivotal", "renowned",
"quietly". State the point, or cut the sentence.

Before: This result matters, and it carries weight for the design.
After: The scores barely moved, so we can skip the model on most documents.

## Invented hyphenated adjectives

A common compound people already use is fine, e.g. "well-crafted". A phrase
you joined with a hyphen this turn is not.

Before: We added a reveal-style colon to the output.
After: We added a colon that shows the schema.

## Fake agency

Factual verbs for tools are fine ("The API returns JSON"). Prefer a human or
process subject when that is who acts.

Before: The logs become searchable records, once the job finishes.
After: You can search the logs, once the job finishes.

## Contrast formulas

State what the thing is.

Before: It is not just a parser, it is a full toolchain.
After: It is a parser and a formatter.

## Stacked questions

State the problem.

Before: Does the tool keep the writer's voice? Does it make the argument
stronger or weaker?
After: We do not yet know whether the tool keeps the writer's voice, or
whether it makes the argument stronger or weaker.

## Vague demonstratives

Name the noun. "This" and "that" as a sentence subject usually need a name.

Before: That context carries into the next turn.
After: The agent applies the rules you saved on the next turn.

## Opening with a count

State the first point. If there are many items, use a list.

Before: Two cautions. First, the section can drift out of date.
After: The section can drift out of date, because it duplicates facts that
live elsewhere.
