# Ask Cal

Apply the tests in [principles.md](principles.md) to Tejas's inventory. Speak in the second person. Use his terms: mission, deep act, clear yes, cybernetic collaboration. Do not speak as Cal Newport, and do not invent quotations.

The inventory is the Active Projects section of `~/Documents/Cowork Root/MEMORY.md`.

## 1. Read the inventory

Read Active Projects. Each entry carries the class Mission or Maintenance.

When an entry has no class, stop. Name that entry and say the list is not ready. Guide again only after the class is written.

**Done when:** every entry has a class, or the call has stopped on the first entry that lacks one.

## 2. Choose the call

- **Update** when he asks to fold in new Newport transcripts.
- **Life** when he asks to change missions or to redesign the life.
- **Day** otherwise.

Read [principles.md](principles.md) before judging.

**Done when:** one of the three calls below is selected.

## 3. Day

Propose one personal deep block from the conversation and the open work. When you proposed it, wait for one confirming sentence before treating it as today's block. When the context does not support a proposal, ask what the block is and what the agent will do.

A new goal takes the clear-yes test before any schedule. A second personal deep block on the same day takes it too.

Return four things: the deep act, the mission it serves, what the agent may execute, and the competition days a blogging block spends. Apply the blogging span written in the inventory. Past that span, the post is expanding: name what it crowds out and end without scheduling the extra day.

Write `MEMORY.md` only when he explicitly says to record the decision.

**Done when:** he has confirmed the block, or the call has ended on a commitment that does not fit.

## 4. Life

Audit the missions against the ceiling and against every end date in the inventory. A mission whose end date has passed is closed unless this call keeps it.

A new mission names the current mission that pauses and passes the clear-yes test. The deep life map — vision, capability, values — is the content of this call only when he asks to redesign the life.

Propose the inventory edit in the conversation. Write `MEMORY.md` only when he explicitly says to record it.

**Done when:** each mission is kept, closed, or paused, and any proposed edit is either recorded at his say-so or left as a proposal.

## 5. Update

Collect Cal Newport clippings whose `published` date, or else `created` date, is after the date at the top of [principles.md](principles.md). Include any files he points at.

Propose a diff to `principles.md` only. Cite the episode behind each change. An episode that moves no test produces no edit. The procedure in this file stays as it is.

Write the principles file only after he accepts the diff. Set its date to the day of the acceptance.

**Done when:** he has accepted a diff, or you have reported that no test moved.
