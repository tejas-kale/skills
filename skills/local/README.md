# Local skills

Skills authored in this repo live here.

Matt Pocock’s skills live under `skills/engineering/`, `skills/productivity/`, and related upstream categories. Edit those **in place** when you need a small tweak (same skill name). Put brand-new skills only under `skills/local/`.
